# Farhan profile website

A responsive single-page portfolio/profile site built with plain HTML, CSS, and JavaScript. The hero includes a lightweight CSS 3D cube and glass interface, with scroll reveals and pointer tilt. No frameworks, paid services, or build step are needed.

## Preview / publish on GitHub Pages

This project is in the `docs/` folder so it does not overwrite the existing WordPress theme project at the repository root. In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/docs`, then save. GitHub Pages will publish the site at `https://rajanafarhan-code.github.io/farhan-premium-wordpress-theme/` after deployment completes.

## Before publishing

In `index.html`, replace `YOUR-EMAIL@example.com` with your actual email address. The portfolio section says the work is in progress; replace it with real work when ready. The biography intentionally does not claim experience, client results, or services you have not confirmed.

The site honors reduced-motion preferences and uses CSS transforms rather than a heavy WebGL dependency. The Google Fonts import is optional; the system font fallback works without it.
